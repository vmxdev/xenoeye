# Front-end Xenoeye Portal

## Дизайн-концепция

Интерфейс выполнен в стиле Network Operations Center: тёмный сине-графитовый фон снижает зрительную нагрузку в диспетчерской, бирюзовый акцент обозначает нормальную телеметрию и активные действия. Информационная плотность выше обычного корпоративного кабинета, но ключевые KPI, источник и временной диапазон визуально разделены.

Принципы:

- операционные показатели видны без прокрутки;
- состояния и роли обозначаются не только цветом, но и текстом;
- интерфейс адаптируется к планшетам и узким экранам;
- пользователь видит только назначенные ему источники;
- прямого доступа из браузера к PostgreSQL нет;
- весь UI остаётся SPA и разворачивается как статические файлы Nginx.

## Разделы

### Вход

Форма корпоративного доступа, обработка просроченной сессии и понятное сообщение об ошибке без раскрытия существования конкретного email.

### Обзор

Объём трафика, пакеты, число агрегированных записей, количество доступных таблиц и время последней записи. Основной график автоматически выбирает таблицу с `octets`, если она доступна.

### Аналитика

Выбор таблицы и числовой метрики. Схема таблицы отображается рядом, поэтому аналитик понимает доступные измерения. Временной ряд строится через безопасный агрегирующий API.

### Пользователи

Доступен администратору. Создаёт персональный кабинет, назначает роль и точный список таблиц. Учётную запись можно отключить без удаления.

### Профиль

Показывает текущую роль и позволяет сменить пароль с проверкой старого.

## Разработка

Требуется Node.js 20 или 22.

```bash
cd frontend
npm install
npm run dev
```

Vite проксирует `/api` на `http://localhost:8000`. Production build:

```bash
npm run build
```

Результат находится в `frontend/dist`. В Docker он копируется в Nginx автоматически.

## Расширение

Новые страницы добавляются в `src/pages`, маршрут — в `src/App.tsx`, пункт меню — в `src/components/Layout.tsx`. Все запросы должны выполняться через настроенный клиент `src/api.ts`, чтобы JWT и обработка 401 применялись одинаково.
